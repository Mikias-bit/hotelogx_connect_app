  DF  # Hotelogx Connect — Engineering Guidelines & Code Conventions

**Document Version:** 1.0.0 (Strict Enforcement)  
**Applies To:** All human engineers and autonomous AI agents contributing to `hotelogx-connect`.

---

## 1. Architectural Invariants

### 1.1. Read-Only PMS Boundary
- **Never create or mutate reservations in this UI:** Rates, availability, and guest stay details are read-only abstractions from external PMS systems.
- **No credit card or payment capture:** All pre-arrival room sales must terminate with a link hand-off to the hotel's direct booking engine.

### 1.2. Dual-Layer Operational Parity
- **Desktop/Tablet = Dashboard Control Centre; Mobile = WhatsApp Operations Layer:**
- Any feature accessible on the dashboard for Housekeeping or Maintenance must be operable via the WhatsApp Simulator (`WhatsAppOps.tsx`).
- Tapping buttons on the WhatsApp Simulator must execute the exact same store actions (`setRoomStatus`, `setTaskStatus`, `setIssueStatus`) that the desktop dashboard invokes.

## 2. Folder & Routing Discipline

```
src/
├── routes/          # File-based routes using flat dotted filenames (e.g. manager.tasks.tsx)
├── components/      # Pure presentation components & shared compound widgets
├── lib/             # Domain model (types.ts), seed data (data.ts), store (store.ts), session (session.ts)
└── styles.css       # Tailwind CSS 4 custom theme tokens
```

1. **Flat Dotted Route Files:**
   - Files in `src/routes/` map directly to URL paths: `front-office.conversations.tsx` -> `/front-office/conversations`.
   - Index routes use trailing `.index.tsx`: `manager.index.tsx` -> `/manager` (`createFileRoute("/manager/")`).
2. **Never Edit `src/routeTree.gen.ts` Manually:**
   - The route tree is automatically generated by TanStack Router Vite plugin. Never commit manual edits to this file.
3. **Component Encapsulation:**
   - One component per file in `src/components/`, named exactly after the file.
   - Use named exports exclusively (`export function TaskComposer(...)`).

## 3. Strict TypeScript Discipline

TypeScript is configured with `strict: true`, `noUnusedLocals: true`, and `noUnusedParameters: true`. An unused import or variable will fail the build.

### 3.1. Absolute Ban on `any`
- Every variable, parameter, and return type must be explicitly typed using interfaces from `src/lib/types.ts`.

### 3.2. Central Domain Union Types (`src/lib/types.ts`)
Always use the centralized domain union types rather than raw strings:

```typescript
// Role definition
export type Role = "manager" | "front-office" | "housekeeping" | "maintenance";

// 8 Discrete Room Turnover States
export type RoomStatus =
  | "Dirty"
  | "Cleaning"
  | "Clean"
  | "Inspected"
  | "DND"
  | "Guest Inside"
  | "Maintenance"
  | "Blocked";

// Task Lifecycle States
export type TaskStatus = "New" | "Assigned" | "In Progress" | "Waiting" | "Completed" | "Escalated";

// Severity & SLA Priorities
export type Priority = "Urgent" | "High" | "Normal" | "Low";

// Guest Communication Channels
export type Channel = "whatsapp" | "gmail" | "outlook" | "email";

// Departmental Scope
export type Department =
  | "Front Office"
  | "Housekeeping"
  | "Maintenance"
  | "Guest Request"
  | "VIP"
  | "Billing"

```

## 4. State Management & Reactivity (`src/lib/store.ts`)

### 4.1. The Single Store Pattern
- The application uses a single TanStack Store instance with the `useApp(selector)` hook.

```typescript
// ✅ CORRECT: Subscribing with a fine-grained selector
import { useApp, selectors } from "@/lib/store";

function RoomList() {
  const rooms = useApp((s) => s.rooms);
  const dirtyCount = useApp(selectors.dirtyRoomsCount);
  return <div>...</div>;
}
```

### 4.2. Zero Component State Mutations
- **Never mutate state inside a React component.**
- **All mutations must pass through exported actions in `src/lib/store.ts`:**
  - `createTask(params)`
  - `setTaskStatus(id, status, note)`
  - `setRoomStatus(number, status, note)`
  - `createIssue(params)`
  - `setIssueStatus(id, status, note)`
  - `takeOver(conversationId)`
  - `returnToAi(conversationId)`
  - `sendReply(conversationId, text, staffName)`
  - `waChoose(threadId, messageId, label)`

### 4.3. Cross-Department Side-Effects Rule
- Actions in `src/lib/store.ts` are deliberately chatty and own all cross-department business consequences:
  - Setting an issue to `Completed` **must** set the room to `Dirty` for a housekeeping recheck.
  - Setting a room to `Clean` or `Inspected` **must** close the matching turnover task and update Front Desk.
  - Completing a guest-linked task **must** append a confirmation message to the guest conversation timeline.

## 5. UI & Styling Standards (Tailwind CSS 4)

### 5.1. No External UI Frameworks
- **Forbidden:** Material UI (MUI), Ant Design, Chakra UI, Bootstrap.
- **Mandatory:** Compose all screens from `src/components/ui.tsx` (`Card`, `Badge`, `Button`, `StatCard`, `Empty`, `SectionTitle`, `Eyebrow`).

### 5.2. Semantic Design Tokens (`src/styles.css`)
Never use arbitrary raw hex codes or standard un-themed Tailwind colors. Use custom theme tokens:
- **Backgrounds:** `bg-paper` (canvas), `bg-surface` (cards), `bg-paper-2` (pills & chips).
- **Typography:** `text-ink` (primary text), `text-ink-2` (secondary), `text-ink-3` (muted), `text-ink-4` (subtle/time).
- **Status Colors (Carries status only — no decorative color splashes):**
  - Green / Good: `text-good`, `bg-good-bg`, `border-good`
  - Amber / Attention: `text-attend`, `bg-attend-bg`, `border-attend`
  - Red / Urgent: `text-urgent`, `bg-urgent-bg`, `border-urgent`
  - WhatsApp Brand: `text-wa`, `bg-wa/10`
  - AI Indigo: `text-ai`, `bg-ai-bg`
- **Typography Scale:**
  - Headings: `font-display` (Fraunces serif)
  - Body: Default sans (Instrument Sans)
  - Room numbers, times, currencies, and IDs: `font-mono` + `tnum` (IBM Plex Mono)

### 5.3. Tone Mapping Standard
Use `statusTone(status)` and `priorityTone(priority)` from `src/components/ui.tsx` to resolve tones. Do not hardcode color switches at call sites.

## 6. Helper Functions & Conventions
- Always format currency via `money(amount)` from `src/lib/utils.ts`.
- Format time strings via `clockNow()` from `src/lib/utils.ts`.
- Generate unique entity keys via `uid(prefix)` from `src/lib/utils.ts`.
- Icons must be imported from `lucide-react` at standard sizes (`size-3`, `size-3.5`, `size-4`).
